A hands-on course on handling forms with what React 19 ships out of the box. It
also covers when a library like React Hook Form still earns its place.

## What You'll Learn

- Handling submissions with React 19 Actions and FormData
- Managing form state and pending UI with useActionState
- Building smart submit buttons with useFormStatus
- Instant feedback and rollback with useOptimistic
- Choosing the right amount of validation
- Using native HTML5 constraints with actions
- Migrating React 18 forms without a rewrite
